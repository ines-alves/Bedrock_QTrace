Status: planned · Owner: M1 · Priority: P0 · Depends on: 1.11

## Plan before implementation

Implement Typer/Rich `cli.py`, publish the qtrace console script, and provide
`scan <paths...> --out --format json,cbom,md --probe`, `eval`, and `ui`. Default
output is native JSON in `out/`; Rich tables display grade, score, counts, top
risks, and incomplete coverage. Export M3/M4 formats only when their writers exist;
explicitly fail an unavailable requested writer instead of silently omitting it.

Evaluation calls the 1.12 implementation when available, otherwise reports that it
is not yet implemented. UI starts M4's API when available without implementing API
or frontend work. Probe delegates to M2's optional adapter. Delay --fail-on and JSON
stdout to optional 1.13 and document that boundary. CLI errors use exit 2; successful
complete scans use exit 0. Partial scans write usable reports but exit 2.
