## Plan before implementation

Implement `pipeline.py` with section 6 run API and ScanOptions. Traverse inputs
deterministically, deduplicate overlapping paths, honor directory exclusions, and
avoid symlink directory cycles. Route recognized files through registered scanners,
choosing specific handlers before generic fallbacks to avoid double scanning.
Document selection precedence using actual integrated scanner names.

Collect yielded ScanError and convert unexpected scanner exceptions into errors
while preserving usable findings. Missing paths, unsupported inputs, unavailable
selected scanners, and requested unsupported probes are explicit errors. Use scan
start time as reference when source time is absent. Build stable ScanResult IDs and
TLS/SSH views from documented session metadata and classified negotiated components.
TLS authentication observability follows the approved UNKNOWN rule.

Use fake scanners for deterministic orchestration tests. When M2–M4 adapters exist,
run the real starter kit; this is the H6 gate, not a claim satisfied by fake scanners.
